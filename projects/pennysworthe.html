PennysWorthe

A next-gen financial analytics dashboard powered by machine learning. PennysWorthe democratizes institutional-grade stock analysis with AI price forecasting, algorithmic risk assessment, and sentiment analysis built directly into the UI.

Project snapshot

Senior capstone project built in Agile sprints. My role focused on networking and infrastructure, including multi-machine hosting, debugging cross-device issues, and shipping the portfolio page and settings architecture. The team delivered a full-stack experience with a Next.js frontend, FastAPI backend, and PostgreSQL data layer.

Key features

AI-powered price prediction. Long Short-Term Memory (LSTM) RNN models analyze historical market data and retrain every 24 hours.

  • Visual forecasting overlays on the price chart.
  • Accuracy widgets showing confidence and past performance.
  • Background scheduling keeps models fresh without blocking the API.

Algorithmic risk and strategy. Six custom algorithms surface market sentiment and trend signals in the stock search flow.

  • Bearish/Bullish sentiment indicators.
  • Golden Cross and Death Cross detection for trend reversals.
  • Risk tolerance fidgets based on volatility and beta.

Interactive market data. Real-time charts, news context, and portfolio tools keep the experience actionable.

  • Responsive Chart.js visualizations.
  • News API sidebar for event correlation.
  • Smart watchlists and a dedicated portfolio page.

Modular algorithmic tuning

PennysWorthe lets users look under the hood by enabling or disabling analysis blocks and fine-tuning sensitivity thresholds to match personal trading styles.

Development journey

  1. Inception with a basic HTML prototype and Python API connections.
  2. Frontend overhaul to Next.js with secure database logins.
  3. Networking and Windows compatibility debugging while adding core algorithms.
  4. Feature expansion: portfolio tools, watchlists, and News API integration.
  5. Final polish with all six algorithms, AI accuracy widgets, and settings page.

Tech stack

  • Frontend: Next.js 15, Tailwind CSS, custom CSS modules, Chart.js.
  • Backend: FastAPI, PostgreSQL.
  • Machine learning: TensorFlow (Keras), Scikit-Learn, Pandas, NumPy.
  • Scheduling: APScheduler for automated model retraining.

Architecture

  1. Next.js client handles UI state, charts, and data visualization.
  2. FastAPI backend manages ML inference, algorithms, and data processing.
  3. PostgreSQL persists users, watchlists, and portfolio data.
  4. Background workers retrain ML models without blocking requests.

Challenges and future roadmap

Challenges overcome:

  • Cross-platform compatibility fixes for Windows users.
  • Networking and hosting across multiple machines and environments.
  • API request limits mitigated with caching strategies.

Future plans:

  • Move to a standalone hosted platform.
  • Expand the UI with additional data visualization tabs.
  • Explore monetization options to support API and server costs.
