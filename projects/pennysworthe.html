APP-02

PennysWorthe

A market analytics dashboard that shows LSTM price forecasts, trend signals, and risk indicators alongside the price chart.

My part
Backend data services, networking, infrastructure
Team
Senior capstone, built in Agile sprints
Stack
Next.js, FastAPI, PostgreSQL, TensorFlow
Result
18% lower MAE than a naive baseline over 12 months

My part

I worked on the backend data services and the networking that kept the project running across multiple machines.

  • Built services that ingest, validate, and preprocess daily market data for 24 assets, feeding automated model training and inference.
  • Built FastAPI and SQLAlchemy REST APIs that serve predictions and historical data.
  • Handled multi-machine hosting and the cross-device bugs that came with it, including Windows compatibility.
  • Shipped the portfolio page and the settings architecture on the frontend.

What it does

Forecasts. LSTM models trained on historical market data retrain every 24 hours on a background scheduler so training doesn't block the API. The chart shows forecast overlays, and accuracy widgets show confidence and past performance.

Signals. Six custom algorithms run in the stock search flow: bullish and bearish sentiment, golden cross and death cross detection for trend reversals, and risk tolerance gauges built from volatility and beta.

Market data. Chart.js visualizations, a News API sidebar for lining up price moves with events, watchlists, and a portfolio page.

Tuning

Users can switch analysis modules on and off and adjust sensitivity thresholds to match how they trade.

Architecture

  1. The Next.js client handles UI state, charts, and visualization.
  2. The FastAPI backend runs ML inference, the signal algorithms, and data processing.
  3. PostgreSQL stores users, watchlists, and portfolio data.
  4. Background workers retrain the models without blocking requests.

How it came together

  1. A basic HTML prototype wired to Python API calls.
  2. A rebuild of the frontend in Next.js with secure logins.
  3. Networking and Windows compatibility fixes while the core algorithms went in.
  4. Portfolio tools, watchlists, and the News API integration.
  5. Final polish: all six algorithms, the accuracy widgets, and the settings page.

What was hard

  • Cross-platform bugs that only showed up for Windows users.
  • Hosting and networking across multiple machines and environments.
  • Third-party API rate limits, which we worked around with caching.
