NMSUandMe

A student networking platform that helps NMSU students connect through shared interests, mutual matching, and event-based meetups. NMSUandMe blends profile-based discovery with algorithmic matching and lightweight social features so meeting people on campus feels intentional rather than random.

Project snapshot

NMSUandMe was a team-based full-stack project built to explore how software can support real-world social connection on campus. Students sign up with an NMSU email, build a profile around their major and interests, and get matched based on similarity. The work emphasized collaborative development, data modeling, and end-to-end feature delivery across the stack.

Core idea

Instead of open feeds or manual searching, NMSUandMe centers on similarity-based discovery. Profiles are surfaced in order of commonality, reducing friction and awkwardness when starting a conversation. The flow borrows familiar swipe patterns while staying focused on campus connections.

Key features

  • Interest-based matching: profiles are converted into vectors from attributes like major and interests, then ranked by similarity.
  • Swipe-style discovery: card stack UI inspired by swipe apps makes exploration fast and lightweight.
  • Mutual matching and messaging: students unlock chat only after a mutual match.
  • Shared event scheduling: users create events and invite connections; accepted invites populate both calendars.

Development approach

Built collaboratively in a small team with responsibilities across frontend UI, backend services, matching logic, and persistence. We focused on clear interfaces between components, incremental feature delivery, and consistent version control and issue tracking.

Architecture overview

  • Frontend: Vue single-page app for profiles, discovery, and chat.
  • Backend: Python services for auth, matching, messaging, and events.
  • Data layer: persistent storage for users, matches, messages, and events.
  • Matching logic: vector similarity ranking to recommend connections.

What I learned

  • Translating social concepts into concrete data models and algorithms.
  • Designing multi-step flows that balance discovery, consent, and communication.
  • Coordinating complex features across a team while keeping a unified product vision.
  • Recognizing how small logic errors can create outsized UX impact.

Closing note

NMSUandMe reinforced how engineering decisions shape user comfort, trust, and engagement. It was a product-driven build that combined algorithms, UI patterns, and backend systems to support real human interaction.
